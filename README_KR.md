## 이 도구가 필요한 이유

샷 프로필은 공 상태, UI 타이밍 및 현재 경험 빌드에 따라 달라집니다. 눈에 보이는 타이밍 그래프를 통해 트리거 창을 측정 가능하게 만들고 개인 세션 테스트에 반복 가능한 기준을 제공합니다.

## 화면 구성

- **01.** 탭, 충전 및 곡선 타이밍을 위한 샷 프로필 카드입니다.
- **02.** 감지된 릴리스 기간이 포함된 전원 타임라인입니다.
- **03.** 점유 및 목표 조건에 대한 볼 상태 표시기입니다.
- **04.** 개인 세션 스위치 및 시작/일시 중지 제어.
- **05.** 빌드 간의 타이밍 변경을 비교하기 위한 실행 기록입니다.

## 한눈에 보기

## 주요 기능

- **샷 타이밍 프로필.** 클라이언트 빌드에 연결된 명명된 프로필에 조정 가능한 설정을 유지합니다.

- **볼 상태 및 UI 확인.** 제어된 테스트 중에 대상, UI 및 타이밍 검사를 표시합니다.

- **개인 서버 테스트 제어.** 세션 결과를 기록하는 동안 명확한 토글 및 비상 정지 기능을 제공합니다.

## 결과 읽는 방법

설정 프로필은 범용 구성이 아닌 하나의 제어된 테스트에 대한 증거입니다. 옆에 표시된 클라이언트 빌드, 대기 시간 및 세션 유형을 읽어보세요. 두 프로필이 다르게 동작하는 경우 한 번에 하나의 설정 그룹을 비교하고 동일한 비공개 테스트 조건을 유지하세요.

## 시작 전 준비

- **클라이언트 빌드 + 테스트 설정**을 준비하고 대상 Blue Lock: Rivals (Roblox) 프로필 또는 세션의 데이터인지 확인합니다.
- 프로필을 변경하기 전에 현재 게임/클라이언트 빌드 또는 데이터 날짜를 기록합니다.
- 이전 결과를 덮어쓰지 않도록 **프로필 및 호환성 참고사항**의 저장 위치를 정합니다.
- 먼저 **샷 타이밍 프로필**을 짧게 시험하고 원본 세이브, 프로필 또는 비교 기록을 보관하세요.

## 첫 실행 전체 과정

1. **Blue Lock Rivals 자동 골 스크립트 참고 자료**을 열고 감지된 Blue Lock: Rivals (Roblox) 빌드 또는 데이터 원본을 확인합니다.
2. 입력이나 프로필을 선택하고 이번 테스트와 관계없는 기본값은 유지한 채 **샷 타이밍 프로필**을 설정합니다.
3. 미리보기나 상태 패널에서 **볼 상태 및 UI 확인**을 확인하고 버전, 필터 또는 감지 경고를 해결합니다.
4. 제어 가능한 작업 하나만 실행합니다. 두 번째 설정을 바꾸기 전에 실제 결과를 미리보기와 비교하세요.
5. 프로필이나 결과를 저장하고 비교 또는 복구에 사용할 **개인 서버 테스트 제어**을 남겨 둡니다.

## 문제 해결

> **자주 발생하는 문제:** 경험 업데이트 후 자동 목표 타이밍이 중단됩니다..

### 프로필이 응답하지 않습니다

클라이언트 빌드 상태를 확인하고 개인 세션이나 교육 세션에서 동일한 설정을 반복하세요.

### 잘못된 대상이 선택되었습니다.

대상 규칙을 하나의 조건으로 줄이고 FOV 또는 상호 작용 미리 보기를 확인합니다.

### 중지 키가 작동하지 않습니다.

주요 충돌을 해결하고 첫 번째 테스트 중에 제어판에 집중하십시오.

## 이럴 때 유용합니다

- 비공개 세션에서 테스트
- 클라이언트 업데이트 후 동작 비교

- [ ] 기본 설정만 활성화한 상태에서 비공개 세션 체크리스트를 반복하세요.
- [ ] 타이밍 값을 조정하기 전에 대상, UI 및 정지 키 검사를 확인하십시오.
- [ ] 이전 프로필이 최신 프로필로 표시되지 않도록 결과를 빌드별로 구분하여 유지하세요.
