## 為什麼需要這個工具

擊球曲線取決於球的狀態、UI 計時和當前的體驗建構。可見的時序圖可讓觸發視窗可測量，並為私人會話測試提供可重複的基線。

## 介面說明

- **01.** 用於點擊、蓄力和曲線計時的擊球設定檔卡。
- **02.** 具有偵測到的釋放視窗的電源時間軸。
- **03.** 用於控球和目標狀況的球狀態指示器。
- **04.** 私人會話開關和開始/暫停控制。
- **05.** 運行歷史記錄以比較建置之間的時間變化。

## 主要功能

- **射擊正時曲線.** 將可調整的設定保留在與客戶端建置相關的命名設定檔中。

- **球狀態和 UI 檢查.** 在受控測試期間使目標、UI 和時序檢查可見。

- **私有伺服器測試控制.** 在記錄會話結果時提供清晰的切換和緊急停止。

## 如何理解結果

設定設定檔是一項受控測試的證據，而不是通用配置。閱讀旁邊顯示的客戶端建置、延遲和會話類型。當兩個設定檔表現不同時，一次比較一個設定組並保持相同的私有測試條件。

## 開始之前

- 準備好 **客戶端建置+測試設置**，並確認它屬於目標 Blue Lock: Rivals (Roblox) 設定或連線。
- 變更設定之前，記錄目前遊戲/用戶端版本或資料日期。
- 先選擇 **設定檔和相容性說明** 的儲存位置，避免覆蓋上一次結果。
- 先用 **射擊正時曲線** 進行一次短測試，並保留原始存檔、設定或比較記錄。

## 完成第一次使用

1. 開啟 **Blue Lock Rivals 自動進球腳本參考**，確認偵測到的 Blue Lock: Rivals (Roblox) 版本或資料來源。
2. 選擇輸入或設定，只調整 **射擊正時曲線**，先保留與本次測試無關的預設值。
3. 在預覽或狀態面板檢查 **球狀態和 UI 檢查**，處理版本、篩選或辨識警告。
4. 只執行一次可控制的操作。在修改第二項設定之前，將實際結果與預覽比較。
5. 儲存設定或匯出結果，並保留 **私有伺服器測試控制** 以便比對或還原。

## 問題排查

> **常見問題:** 體驗更新後自動目標計時中斷.

### 設定檔停止回應

檢查客戶端建置狀態並在私人或培訓課程中重複相同的設定。

### 選擇了錯誤的目標

將目標規則簡化為一種條件並驗證 FOV 或互動預覽。

### 停止鍵失靈

在第一次测试期间解决关键冲突并保持控制面板的焦点。

## 適合使用情境

- 記錄已知良好的設置
- 在私人會話中進行測試
- 比較客戶端更新後的行為

## 遊戲更新之後

- [ ] 在工作設定檔的副本旁邊記錄新的客戶端版本。
- [ ] 重複私人會話清單，僅啟用主要設定。
- [ ] 在調整計時值之前確認目標、UI 和停止鍵檢查。
- [ ] 將結果按建置分開，這樣舊的設定檔就不會顯示為目前的設定檔。
