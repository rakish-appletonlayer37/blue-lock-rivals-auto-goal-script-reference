## Por qué existe esta herramienta

Los perfiles de tiro dependen del estado de la pelota, el tiempo de la interfaz de usuario y la experiencia actual. Un gráfico de tiempo visible hace que la ventana de activación sea mensurable y brinda a las pruebas de sesiones privadas una línea de base repetible.

## Recorrido por la interfaz

- **01.** Tarjetas de perfil de tiro para sincronización de tap, carga y curva.
- **02.** Línea de tiempo de energía con la ventana de lanzamiento detectada.
- **03.** Indicador del estado del balón para posesión y condiciones del objetivo.
- **04.** Interruptor de sesión privada y controles de inicio/pausa.
- **05.** Ejecute el historial para comparar cambios de tiempo entre compilaciones.

## Qué hace

- **perfiles de sincronización de tiro.** Mantiene la configuración ajustable en perfiles con nombre vinculados a la compilación de un cliente.

- **comprobaciones de estado de bola y UI.** Hace que las comprobaciones de objetivos, UI y tiempos sean visibles durante una prueba controlada.

- **controles de prueba de servidor privado.** Proporciona una conmutación clara y una parada de emergencia mientras registra el resultado de la sesión.

## Cómo interpretar el resultado

Un perfil de configuración es evidencia de una prueba controlada, no de una configuración universal. Léelo con la compilación del cliente, la latencia y el tipo de sesión que se muestran al lado. Cuando dos perfiles se comportan de manera diferente, compare un grupo de configuración a la vez y mantenga las mismas condiciones de prueba privadas.

## Solución de problemas

> **Problema habitual:** El tiempo de objetivo automático se interrumpe después de una actualización de experiencia..

### El perfil deja de responder

Verifique el estado de la compilación del cliente y repita la misma configuración en una sesión privada o de capacitación.

### Se seleccionó el objetivo equivocado

Reduzca las reglas de destino a una condición y verifique el FOV o la vista previa de la interacción.

### La tecla de parada falla

Resuelva conflictos clave y mantenga el panel de control enfocado durante la primera prueba.
