## 为什么需要这个工具

击球曲线取决于球的状态、UI 计时和当前的体验构建。可见的时序图使触发窗口可测量，并为私人会话测试提供可重复的基线。

## 界面说明

- **01.** 用于点击、蓄力和曲线计时的击球配置文件卡。
- **02.** 具有检测到的释放窗口的电源时间线。
- **03.** 用于控球和目标状况的球状态指示器。
- **04.** 私人会话开关和开始/暂停控制。
- **05.** 运行历史记录以比较构建之间的时间变化。
