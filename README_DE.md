## Warum es dieses Tool gibt

Schussprofile hängen vom Ballzustand, dem UI-Timing und dem aktuellen Erfahrungsaufbau ab. Ein sichtbares Zeitdiagramm macht das Auslösefenster messbar und gibt Tests für private Sitzungen eine wiederholbare Basislinie.

## Die Oberfläche

- **01.** Schussprofilkarten für Tipp-, Ladungs- und Kurven-Timing.
- **02.** Power-Timeline mit dem erkannten Release-Fenster.
- **03.** Ballzustandsanzeige für Ballbesitz und Zielbedingungen.
- **04.** Privatsitzungswechsel und Start-/Pause-Steuerelemente.
- **05.** Laufverlauf zum Vergleichen von Zeitänderungen zwischen Builds.

## Was das Tool macht

- **Schuss-Timing-Profile.** Behält anpassbare Einstellungen in benannten Profilen bei, die an einen Client-Build gebunden sind.

- **Ballstatus- und UI-Prüfungen.** Macht Ziel-, UI- und Timing-Prüfungen während eines kontrollierten Tests sichtbar.

- **Testkontrollen für private Server.** Bietet ein klares Umschalten und einen Notstopp während der Aufzeichnung des Sitzungsergebnisses.

## Ergebnisse richtig lesen

Ein Einstellungsprofil ist ein Beweis für einen kontrollierten Test, nicht für eine universelle Konfiguration. Lesen Sie es mit dem daneben angezeigten Client-Build, der Latenz und dem Sitzungstyp. Wenn sich zwei Profile unterschiedlich verhalten, vergleichen Sie jeweils eine Einstellungsgruppe und behalten Sie die gleichen privaten Testbedingungen bei.

## Fehlerbehebung

> **Häufiges Fehlerbild:** Das automatische Ziel-Timing bricht nach einem Erlebnis-Update ab.

### Das Profil reagiert nicht mehr

Überprüfen Sie den Client-Build-Status und wiederholen Sie die gleiche Einrichtung in einer privaten oder Schulungssitzung.

### Das falsche Ziel wurde ausgewählt

Reduzieren Sie die Zielregeln auf eine Bedingung und überprüfen Sie das FOV oder die Interaktionsvorschau.

### Die Stopptaste schlägt fehl

Lösen Sie wichtige Konflikte und halten Sie das Bedienfeld während des ersten Tests konzentriert.
